BASELINE VS VERSION 2: GROUP PERFORMANCE

Method
Re-evaluated the saved best Baseline checkpoint (epoch 6) and saved best
Version 2 checkpoint (epoch 8) using the same unaugmented processed images,
batch size 4, CUDA, and fixed probability threshold 0.5. No training occurred.
Dice and IoU were calculated per image, then averaged equally within each group.
Changes in the CSV are Version 2 minus Baseline on the 0-to-1 score scale.
Every test image and all 99 validation images were evaluated by both models.

Results (changes below are percentage points)
- p_003, 505 images: Dice 0.3848 -> 0.5268 (+14.20 points);
  IoU 0.2745 -> 0.3796 (+10.50 points). Largest improvement.
- p001, 100 images: Dice 0.3037 -> 0.3892 (+8.55 points);
  IoU 0.1973 -> 0.2778 (+8.06 points). Improved, but scores remain modest.
- p006, 361 images: Dice 0.5972 -> 0.6063 (+0.91 points);
  IoU 0.4612 -> 0.4729 (+1.16 points). Small improvement.
- Validation video_7 / Patient 4, 99 images: Dice 0.5313 -> 0.5085
  (-2.28 points); IoU 0.3813 -> 0.3588 (-2.24 points). Did not benefit.

Interpretation
Augmentation benefited all three test groups on average, especially p_003.
That group is also the largest test group, so it contributes most to the
overall test-score improvement. Average improvement does not mean every image
improved. The small p006 difference is not evidence of statistical significance.
Patient 4 validation performance declined, so augmentation was not uniformly
beneficial across held-out groups. This supports the earlier mixed conclusion:
better performance on this test set, but not consistently better generalization.

Identity and evaluation limitations
p_003 is associated with Patient 3 using exact-image matches and the supplied
publication mapping. Validation video_7 is Patient 4. The publication-level
patient mappings for p001 and p006 remain unverified; these names are image
groups, not newly confirmed patient identities. Nearby video frames are
correlated. This is a single-seed exploratory comparison, not a statistical
demonstration of improvement across independent patients. Validation scores
are from checkpoints selected on validation Dice, not a fresh external test.

Integrity
Checkpoint SHA-256 hashes were unchanged before and after evaluation.
The original Dataset validated processed image/mask hashes while loading.
Datasets, splits, architecture, and trained weights were not changed.
Full-precision results: metadata/group_performance_comparison.csv
